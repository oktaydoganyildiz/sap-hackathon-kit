# SAP-samples/integration-mcp-gateway

https://github.com/SAP-samples/integration-mcp-gateway

Tür: arac (hands-on tutorial reposu)

SAP Integration Suite'in **MCP Gateway** yeteneğini gösteren resmi SAP-samples hands-on eğitim reposu. Senaryo: BestRun firması bir tedarik/procurement risk değerlendirme ajanı için, Business Partner, Risk Analytics (3. parti, ör. Everstream), Plant ve Material API'lerini **API Composition** ile tek bir "Business Data Graph" halinde birleştirip, bunu **MCP server** olarak paketleyip expose ediyor. AI ajanlar bu composed API'yi MCP tool olarak çağırarak, güvenli ve governed şekilde enterprise business context'e (tedarikçi, stok, risk, lojistik mesafe) erişip en uygun tedarikçiyi seçebiliyor. Ajan kurulumu kapsam dışı; odak API composition + MCP server oluşturma/deploy + MCP client (MCP Inspector) ile test. Tüm API'ler bu eğitim için public mock API. İki egzersiz: (1) Business Data Graph ile Unified Supply Risk API inşası, (2) MCP server oluşturma/deploy/kullanma. Apache-2.0 lisanslı, son push 2026-09-27 (aktif). SAP BTP Integration Suite tenant ve API Management/Composition bilgisi faydalı ama zorunlu değil.
