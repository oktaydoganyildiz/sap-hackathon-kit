# End to End guide to setup Joule, SAP Build Process Automation, and SAP Build Work Zone on SAP BTP

Link: https://community.sap.com/t5/technology-blog-posts-by-sap/end-to-end-guide-to-setup-joule-sap-build-process-automation-and-sap-build/ba-p/14345869

Yazı türü: tarif

## Özet
BTP subaccount üzerinde Joule, SAP Build Process Automation (SBPA) ve SAP Build Work Zone'un (standard edition) uçtan uca kurulumunu anlatan adım adım rehber. Cloud Identity Services (custom identity provider) ile trust kurulumu, entitlement/instance oluşturma, role collection atamaları ve Joule Booster çalıştırma sırasını detaylandırıyor. Ayrıca Cloud Identity tenant'ın BTP Cockpit Systems'de görünmemesi gibi yaygın prerequisite hatasının Cloud Reporting tool üzerinden çözümünü gösteriyor. SBPA tarafında Joule skill geliştirme akışını (Destination → Environment → Joule Action → Project/Workflow → Work Zone/Standalone entegrasyonu) açıklıyor. Work Zone tarafında Site, Catalog, Role, Channel Manager gibi bileşenleri ve Joule AI Copilot'un Settings üzerinden nasıl aktive edileceğini özetliyor.
