# secondsky/sap-skills

https://github.com/secondsky/sap-skills

Yazı türü: arac

GitHub reposu: Claude Code ve Codex CLI için 40 SAP geliştirme plugin'i ("SAP Skills for AI Coding Assistants"), context-based auto-activation ile çalışıyor. Kapsam beş kategori: Tooling & Development (5, API policy/style, browser automation, dependency security, HANA CLI), SAP BTP Platform (15, best-practices, BAS, CIAS, Cloud Logging, Cloud Identity, core, CTM, Connectivity, Developer Guide, Integration Suite, ISA, Job Scheduling, MDI, Service Manager, Work Zone Advanced), UI Development (4, Fiori Tools, SAPUI5 + CLI + Linter), Data & Analytics (7, BW query, Datasphere, HANA Cloud Data Intelligence, SAC custom-widget/planning/scripting/test-automation) ve Core Technologies (9, ABAP, ABAP CDS, AI Core, CAP/Capire, Cloud SDK AI + Python, HANA ML, RPT-1, SQLScript). 7 plugin MCP server, 14'ü agent, 8'i hook, 1'i (sap-cap-capire) LSP içeriyor. Kurulum: `/plugin marketplace add secondsky/sap-skills` (Claude) veya `codex plugin marketplace add .` (Codex), ya da `npx skills add secondsky/sap-skills`. GPL-3.0 lisanslı, 462 yıldız, son push 2026-10-05 (v2.4.0, 2026-07-21). Envanter taramasına göre bu marketplace'ten 24 plugin zaten aktif, 9'u kurulu ama kapalı; `sap-datasphere` MCP adı ayrı bir marketplace (sap-datasphere-cowork) ile çakışıyor.
