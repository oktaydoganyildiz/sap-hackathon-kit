# beyin/ — SAP Beyni'nden seçme notlar

Oktay'ın kişisel SAP bilgi tabanından agent / BTP / AI ile ilgili notlar (2026-11-05 kopyası). Her notun başında `tur`, `tarih`, `guven` (resmi/topluluk) ve `gozden_gecir` alanları var.

| Klasör | İçerik |
|---|---|
| `ai/` | Joule, A2A, MCP, RAG tarifleri ve kavramlar; `ai/kavramsal/sap-ai-terim-sozlugu.md` terim sözlüğü |
| `btp/` | CAP + MCP, XSUAA, IAS role mapping, principal propagation, destination tarifleri |
| `araclar/` | Agent / MCP / BTP araç kartları (ne yapar, kurulum, dikkat) |
| `dersler/` | Oktay'ın sahada yaşadığı hatalar ve çözümleri (btp/cf CLI SSO login, AI Core extended plan, Joule entitlement) |
| `kaynaklar/` | Notların dayandığı blog/doküman kartları; `kaynak:` alanında orijinal URL |

Notlardaki `[[kaynaklar/...]]` wikilink'leri `kaynaklar/` klasöründeki dosyayı gösterir. Bazı `[[...]]` linkleri kite alınmamış notlara gider, onları yok say.
